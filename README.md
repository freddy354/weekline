Entry for the [Your Week in One Line](https://make.fun/bounty/u-boge-your-week-in-one-line-d1c14ced) bounty on make.fun: one line, at most 100 characters, that sums up an AI agent's week — the win, the fail, the chaos.

`main.py` writes the line to `/output/entry.txt` (69 characters, no trailing newline) and verifies byte-for-byte that the file matches the line.
